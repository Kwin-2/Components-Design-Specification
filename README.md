# 懋略设计规则库（Maolue Design Rules Library）

电池包零部件设计规范在线自查库 —— 懋略 · 电池系统设计部内部工程规范。

> 覆盖托盘、上盖、冷板、铝排/铜排、FPC、低压线束、高压电缆、BMU、紧固件、绝缘膜、结构胶/导热材料、密封圈、水管、模组端板/拉条、塑胶件（含/不含螺母模内注塑）、气凝胶、保温棉、动力插头、温感等全部电池包零部件。

## 访问方式

- 站点入口需输入**访问令牌**（由设计部统一告知工程师），令牌错误无法解密任何规范内容；
- 全部规范数据以 **AES-256-GCM 密文**存储在仓库中（`data/bundle.json`），密钥由访问令牌经 PBKDF2-SHA256（15 万次迭代）派生，明文数据从不落盘、不入库；
- 未经授权禁止抓取、复制、转存本页面内容。

## 功能

- **按制造工艺分类**：钣金冲压 / 铝挤压 / 压铸 / 注塑 / 机加工 / 冷板 / 密封 / 胶粘 / 绝缘隔热 / FPC / CCS 组件 / 线束电缆 / 连接器 / BMU / 电气安全器件（MSD·熔断器·分流器等）/ 储能系统架构 / 紧固件 / 端板拉条 / 消防防爆 / 表面处理 / 焊接，共 21 份设计规范 + 1 份总览。
- **变更验证查字典**：勾选零件类别与变更类型（材料/工艺/表面处理/供应商/配方/场地等），自动生成零件级→装配级→Pack级验证清单、PPAP 要求与十步流程（依据《变更验证管理办法 ML-GL-01》，配套 Excel checklist 内部发放）。
- **技术要求生成器**：按 19 类物料（ML-TR-01~19）选择通用技术要求，勾选防腐位置后一键生成可复制的技术要求文本，粘贴进图纸技术要求栏。
- **零件检索**：按电池包零件类型查找对应规范。
- **表面处理选型器**：按「P1~P4 防腐位置分级 × 材料 × 导电需求 × 特殊条件」推荐表面处理与盐雾要求（包外件与包内件防腐严格区分）。
- **在线自查清单**：每份规范附带打勾式自查清单，进度保存在浏览器本地。
- **全文搜索**：关键词即时检索，规则条目优先。
- **规则分级**：🔴 强制（安全/DFM 底线）与 🟢 推荐（良率/成本，需评审说明）。

## 在线部署（GitHub Pages）

本仓库即站点根目录（含 `.nojekyll`），在仓库 `Settings → Pages → Deploy from a branch → main / root` 即可。站点纯静态、无构建依赖。

## 目录结构

```
├── index.html           # 站点入口（含访问令牌门禁）
├── robots.txt           # 禁止搜索引擎收录
├── assets/              # 样式与前端逻辑（原生 JS，无依赖）
├── data/
│   └── bundle.json      # 全部规范数据的 AES-256-GCM 密文（唯一数据文件）
└── README.md
```

## 内容更新方法（内部维护）

规范内容源为工作区 `content/*.json`（单一数据源，网页与 Word 共用）：

1. 修改对应 JSON 后用 `python scripts/build_docx.py` 重新生成 Word（内部发放）；
2. 用 `python scripts/build_site.py` 刷新明文数据；
3. 用 `node scripts/encrypt_data.mjs "<访问令牌>"` 重新加密生成 `data/bundle.json`；
4. 提交推送，网页即更新。**换令牌需重新执行第 3 步并通知全员。**

## 数据与内容说明

- 防腐分级（P1~P4）与盐雾要求依据 GB/T 10125 中性盐雾试验；
- 安规依据 GB 38031《电动汽车用动力蓄电池安全要求》与 GB/T 18384.1 等；
- 钣金规范参考华为 DKBA4031-2003.06《钣金结构件可加工性设计规范》的工艺参数体系；
- 各份规范的"编制参考来源"章节列出完整出处。
